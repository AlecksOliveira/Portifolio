# Documentação

Documentos de apoio do portfólio: planejamento da estrutura, roteiro da apresentação e materiais de referência.

## Planejamento do repositório

- **Projetos acadêmicos:** trabalhos das disciplinas, uma pasta por projeto.
- **Projetos pessoais:** projetos fora da faculdade.
- **Documentação:** esta pasta.
- **Página (GitHub Pages):** `index.html` na raiz, que lista os projetos e links.

## Boas práticas adotadas

- Um README.md em cada pasta de projeto.
- Mensagens de commit curtas e descritivas.
- Versão da página marcada com a tag `v1.0`.
