# Engenharia de Software

Atividade de modelagem da disciplina de **Engenharia de Software**.

## Sobre

O trabalho modela um **sistema de matrícula em disciplinas de uma universidade**. Ele traz o modelo de contexto do sistema, mostrando como o aluno interage com o sistema e com o catálogo de cursos, e um diagrama de casos de uso em UML. No diagrama aparecem as relações de inclusão (`include`), como verificar pré-requisitos e verificar vagas disponíveis, e as relações opcionais (`extend`).
